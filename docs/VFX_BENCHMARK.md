## 2D → 탑다운 전환에서 잃은 것 (old2d_sw1 vs base_sw1)
| 요소 | 2D 버전 | 탑다운(시작 시점) |
|---|---|---|
| 캐릭터 존재감 | 화면 높이의 약 1/3 | 약 1/8, 암전 속에 묻힘 |
| 검기 | 두꺼운 초승달, 흰 핵+붉은 몸통, 캐릭터 2배 크기 | 굵기 몇 픽셀의 직선(레이저처럼 보임) |
| 대비 | 붉은 달·산 배경 위 밝은 이펙트 | 전장을 .84~.92 암전 → 사실상 검은 화면 |
| 표적 | 한 점(수정)에 타격 집중, 히트 수·대미지 표기 | 화면 전체에 분산, 중심 없음 |
| 연출 수단 | 인게임 포즈 + 글자 스탬프 | 컷인 띠(클로즈업 이미지), 2색 단색 임팩트 프레임 |
| 높이·깊이 | 옆 시점이라 자연히 있음 | 전부 평면 선 |

복원한 것: 두꺼운 초승달 검기(이제 바닥 평면에 눕혀 원근 적용), 흰 핵/본색/테두리 3톤, 캐릭터 조명.
탑다운에 새로 얻은 것: 균열에서 수직으로 솟는 빛의 벽(높이), 굴절 슬립, 전장 조명.

## 레퍼런스에서 가져온 문법 (에셋 복제 없음)
- 격투게임식 셀 이펙트: 2~3톤 단색 면, 12fps 계단 움직임
- 액션 RPG 각성기: 범위 예고(바닥 링) → 정적 → 시간차 폭발
- 사쿠가: 스미어 잔상(포즈 실루엣을 진행 반대 방향으로 늘림), 임팩트 프레임, 예비 동작-정지-해방

## 현재 품질의 한계
- 캐릭터 그림이 옆모습 스프라이트(약 300px)라 줌인 한계가 있고 탑다운 원근과 어긋난다.
