- 캡처: `node _gen/cap/cap.js <cls> <ult> "초,…" 이름.jpg --cols N --tw W` / 조각 `--cls --piece --ts --name` / 임의 `--eval`.
- 영상: `--eval "__boot(cls,ult,{fill:4}); await new Promise(r=>setTimeout(r,1500)); await __inc('_gen/v3/h.js'); return await __film('이름',초,30,.75);"` → ffmpeg → `_gen/review/`.
- 안정성: `--eval "await __inc('_gen/v3/smoke.js'); return await __smoke('<cls>',5);"` / 성능·복구: `--eval "return await __perf('<cls>','<ult>')"`.
- 원화: `_gen/g4*.json` → `python _gen/run_batch.py m.json log.json 2` → "failed"여도 `~/.codex/generated_images`에 있음(생성 시각·크기로 식별, **반드시 열어서 내용 확인**) → 가공(`_gen/v3/proc3.py` 참고) → `assets/v3_*.webp` → `vfx3.js` TEX 목록·`VFX_KIT.md`.
- 독립 검증: 새 general-purpose 에이전트에 시트 경로만 주고 채점(코드·이전 점수 비공개). 검증자마다 ±4 흔들림.

메뉴 "스틱맨 모드" 옵션(`sv.opt.stick`). 영웅만 뼈대로 그림. `rpg.js`의 `STK()`, `surv.js`의 `drawPlayerBody` 윤곽광.

## 미검증
