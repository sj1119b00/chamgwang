**방법**

- 검은사막: 클래스별 약 1초 간격 24프레임 시트 25장.
- 아이온2: 0.5초 간격 352프레임.
- 사운드: 재생 중 음량과 6개 주파수 대역(80Hz 미만 / 80~250 / 250~1k / 1k~4k / 4k~10k / 10k 이상)을 측정.

**한계 (반드시 함께 읽을 것)**
- 사운드는 직접 들은 것이 아니라 측정 수치에서 추정했다. 음색(금속성, 목소리 등)은 판단하지 못했다.
- 검은사막과 아이온2 영상은 배경음악이 깔려 있어 효과음을 분리하지 못했다. 사운드 분석은 로스트아크에만 해당한다.
- 프레임 간격보다 짧은 연출은 놓쳤을 수 있다. 검은사막은 스킬 하나가 0.5~1.5초라 개별 스킬 단위가 아니라 클래스 단위로만 봤다.
- 제작 기법(4장)은 게임 파일을 연 것이 아니라 화면에서 역추정한 것이다. 화면에 보이는 구성은 사실, 만드는 방식은 추정이다.

## 1. 로스트아크 각성기: 공통점

### 시각 연출
1. **시전 신호가 같다.** 시전 0.3~0.5초 안에 캐릭터 위치에서 청백색 원형 섬광이 한 번 터진다. 스킬 색과 무관하다.
2. **4단 구조.** 준비(0.3~1.2초) → 축적(색·크기가 커짐) → 절정(1~3프레임 화면 섬광) → 잔해(1~4초).
3. **절정에서 화면 전체가 반응한다.** 방사형 블러, 색수차, 화이트아웃이 겹친다. 색수차는 최소 15개 스킬에서 확인했다.
4. **바닥에 흔적이 남는다.** 그을음·균열·용암·잔불이 2~4초 남았다가 입자로 흩어진다.
5. **직업마다 색이 1~2개로 고정된다.** 버서커 적·주황, 워로드·홀리나이트 금·백, 디스트로이어 청백, 데모닉 흑·자·적, 도화가 먹색·분홍·금색.
6. **주변 조명이 바뀐다.** 이펙트 색이 바닥에 실제로 비친다. 큰 기술은 화면 전체에 색을 입히거나 가장자리를 어둡게 한다.
7. **밝기 대비로 강조한다.** 절정 직전에 어두워졌다가 한 번에 밝아진다.

### 사운드 (측정 기준)
1. **배경음악이 없다.** 스킬 사이는 −87dB 무음, 스킬 중 평균은 −17~−24dB.
2. **시전음이 가장 밝다.** 약 절반의 스킬에서 고음역 최대 순간이 시전 섬광과 겹친다.
3. **무게는 저음에 있다.** 250Hz 이하가 4kHz 이상보다 평균 10dB쯤 크다. 서브베이스(80Hz 미만) 최대 순간은 화면 절정과 0.1~0.3초 안에서 일치한다.
4. **큰 타격 직전에 0.15~0.3초 소리가 빠진다.** 테라 브레이크 3·4타, 천하섬멸옥, 펜리르 발사, 폴른 루인 2차 폭발.
5. **잔향은 0~3초.** 예외는 장판형인 심판의 창(8.7초).
6. **타격 수가 화면과 맞는다.** 한 방형은 소리도 한 번, 연타형은 타격 수가 일치, 지속형은 끊김 없는 한 덩어리.

## 3. 로스트아크 각성기: 이펙트가 만들어진 방식

### 부품 목록
| 부품 | 화면에서 보이는 모습 | 추정 제작 방식 | 대표 장면 |
|---|---|---|---|
| 입체 형체 | 대검, 카드, 방패, 용암 가시, 포탑 | 3D 모델에 발광 무늬, 크기·투명도 변화 | 버스크 퓨리, 프리즈매틱 미러, 용왕불패 |
| 흐르는 무늬 도형 | 광선, 돔, 구체, 회오리, 충격 고리 | 원통·반구·고리에 무늬를 흘림 | 극상마섬광, 엔비스카, 천하섬멸옥 |
| 연속 그림 연기·불 | 뭉게뭉게 변하는 연기와 화구 | 여러 장을 넘기는 판, 음영 포함 | 종말의 부름, 파이널 익스플로전 |
| 입자 | 불티, 파편, 꽃잎, 반짝임 | 작은 판·조각 수십~수백 개 | 체인 오브 벤전스, 진경산수 |
| 띠 궤적 | 무기·탄이 지나간 꼬리 | 경로를 따라 띠를 늘이고 뒤부터 흐려짐 | 운석 꼬리, 플래시 블링크 |
| 번개 줄기 | 가늘고 꺾인 밝은 선 | 꺾인 선 그림을 1~2프레임씩 교체 | 테라 브레이크, 폴른 루인 |
| 바닥 문양·흔적 | 마법진, 예고 원, 그을음, 균열 | 바닥 표면에 그림을 덧씌움 | 심판의 창, 버스크 퓨리 |
| 굴절 왜곡 | 충격 순간 배경이 일그러짐 | 투명 고리가 뒤 화면을 밀어냄 | 극멸권, 무극권 |
| 빛 번짐·렌즈 섬광 | 밝은 부분 주변의 뿌연 빛 | 화면 후처리와 섬광 그림 | 알리사노스의 심판 |
| 화면 전체 효과 | 블러, 색수차, 화이트아웃, 색 입히기 | 특정 순간에 후처리 값을 올렸다 내림 | 진경산수, 폴른 루인 |
| 실제 조명 | 이펙트 색이 바닥에 비침 | 이펙트 위치에 색 조명 | 용왕불패, 빅뱅 |
| 카메라 | 흔들림, 확대·축소, 장면 전환 | 스킬 타임라인에 카메라 동작 | 알리사노스의 빛, 레퀴엠 |

### 레이어 순서 (아래에서 위로)
1. 바닥층: 문양, 그을음.
2. 어두운 덩어리층: 연기, 암석, 먹처럼 뒤를 가리는 것.
3. 주인공 형체층: 그 스킬만의 형체.
4. 빛층: 불꽃, 번개, 섬광. 겹칠수록 하얗게 탄다.
5. 입자층: 불티와 파편.
6. 화면층: 블러, 색수차, 색 입히기.

예시
- 폭열각(233.0초): 그을음 고리 → 검은 연기 띠 → 주황 용암 돔 → 돔의 어두운 외곽선 → 불티.
- 파이널 익스플로전(320.9초): 연기 깔개 → 버섯구름 → 얇은 주황 고리 → 파편.
- 빅뱅(51.6초): 유리 같은 겉껍질 → 안쪽 불꽃 무늬 → 바닥 불꽃 고리 → 주변 조명.

### 유형별 조립법
| 유형 | 주인공 부품 | 받쳐 주는 부품 | 해당 스킬 |
|---|---|---|---|
| 광선형 | 원통 2~3겹(흰 심, 색 겉, 흐린 외곽) | 시작점 섬광, 끝점 불꽃, 잔해 길 | 극상마섬광, 펜리르, 헤비 터렛 |
| 폭발형 | 화구와 충격 고리 | 화면 섬광, 블러, 연기, 그을음 | 빅뱅, 파이널 익스플로전 |
| 낙하형 | 위에서 떨어지는 입체 형체 | 낙하 궤적, 먼지 고리, 균열 | 죽음의 운명, 종말의 부름 |
| 참격형 | 초승달 띠와 직선 줄기 | 색수차, 카메라 흔들림, 잔상 | 적룡질풍격, 블레이드 어설트 |
| 영역형 | 바닥 문양과 반투명 돔 | 도는 고리, 떠오르는 반짝임 | 가디언의 수호, 오라토리오 |
| 소환·설치형 | 입체 캐릭터나 기계 | 등장 섬광, 주기 공격 | 켈시온, 헤비 터렛 |
| 화면 연출형 | 화면 전체 색·안개·격자 | 장면 전환, 단발 타격 | 황혼의 눈, 폴른 루인 |

### 세부 기법
- 빛은 3겹: 거의 흰 심, 채도 높은 중간, 넓고 흐린 겉.
- 색은 흰색 → 원색 → 어두운 색 순으로 식는다.
- 보색을 테두리에 쓴다 (청록 잔상 옆 붉은 줄, 보라 바닥 위 주황 레이저).
- 규칙적 도형(고리, 마법진, 광선)과 불규칙한 덩어리(연기, 파편, 번개)를 짝짓는다.
- 입체감은 위로 솟은 형체 하나로 만든다.
- 절정은 0.1~0.3초, 잔해가 2~4초 남아 강했다는 인상을 이어 준다.
- 절정 섬광은 1~3프레임 동안 형체를 일부러 지우고, 다음 프레임에 결과를 보여 준다.

### 특이한 구성
- 진경산수: 유일하게 빛이 아니라 어두운 먹. 흰 안개로 먼저 밝게 덮고 검은 붓질을 불투명하게 얹어 명암을 뒤집었다.
- 월식: 카덴차: 달은 바닥의 원판, 분신은 흰 윤곽 복제, 참격은 굵기 없는 검은 직선.
- 엔비스카의 권능: 구체 표면 무늬 자체가 무지개색.

## 4. 검은사막 각성 스킬

### 영상 구성
클래스마다 타이틀 카드(약 2초) → 근접 연출 컷(낮은 시점, 5~7초) → 야간 풀밭에서의 스킬 시연(10~20초) → 각성 이동기(3~5초) 순서다.

### 공통점
1. **시점이 캐릭터 등 뒤다.** 로스트아크의 위에서 보기와 달리 이펙트가 화면 깊이 방향으로 뻗는다.
2. **스킬 하나가 0.5~1.5초로 짧고 끊김 없이 이어진다.** 준비 동작이 거의 없고 무기 휘두름과 동시에 이펙트가 나온다.
3. **이펙트가 무기 궤적을 따른다.** 굵은 초승달 띠가 휘두른 방향 그대로 남고, 그 방향으로 불티와 파편이 뿌려진다.
4. **입자가 매우 많고 길게 늘어난다.** 점이 아니라 진행 방향으로 늘어난 선 모양이라 속도감이 난다.
5. **클래스마다 색이 하나다.** 아래 표 참고.
6. **어두운 배경에서 시연한다.** 야간 풀밭이라 빛이 강하게 떠 보인다.
7. **잔해가 거의 없다.** 대부분 1초 안에 사라진다. 예외는 가디언(바닥 불길), 위자드(용암).
8. **화면 효과는 순간에만 쓴다.** 돌진 때 방사형 블러, 강타 때 짧은 확대와 흔들림.
9. **자주 쓰는 형체는 다섯 가지.** 초승달 참격 띠, 바닥을 도는 고리·소용돌이, 가는 세로 빛기둥, 방사형 줄기 폭발, 번개.

### 클래스별 색과 특징
| 클래스 | 주색 | 눈에 띄는 형체 |
|---|---|---|
| 워리어 | 적색 | 바닥 붉은 고리, 세로 붉은 기둥, 붉은 구체 방어막 |
| 레인저 | 청록·민트 | 가는 초승달 여러 겹, 청록 구체, 바닥 소용돌이 |
| 소서러 | 보라·검정 | 검은 파편 덩어리, 보라 번개 고리, 반원 참격 호 |
| 자이언트 | 주황 불·노랑 | 화구 폭발, 노란 불티 분수, 화염 돌진 |
| 금수랑 | 청록·녹색 | 녹색 반구, 청색 직선 참격, 검은 짐승 소환 |
| 무사 | 주황 불 | 화염 참격 띠, 바닥 화염 고리, 세로 화염 호 |

| 쿠노이치 | 금·노랑 | 금빛 회전 고리, 세로 빛기둥, 가는 궤적 |
| 닌자 | 진홍 | 붉은 직선 참격 다발, 붉은 소용돌이, 분신 |
| 위자드 | 불 + 물 | 화염 지대, 물기둥, 불·물 정령 소환 |
| 위치 | 번개 청색 + 흙 | 번개 다발, 번개 구체, 흙 골렘 소환 |

| 세이지 | 금색 번개 | 번개 줄기, 공중 균열, 만화경 같은 기하 문양 |
| 커세어 | 흰 물안개 | 물보라, 안개, 바다 생물 소환 |
| 드라카니아 | 청색 + 주황 | 청색 반구와 고리, 화염 대검, 용 날개 |
| 우사 | 청색 | 청색 꽃·나비 형상, 번개, 청색 구체 |
| 매구 | 보라·자홍 | 보라 불꽃 입자, 여우불 구체, 자홍 참격 |

### 사운드
측정한 18개 구간 모두 평균 −16~−18dB로 일정하고, 조용한 구간이 0%였으며, 큰 소리와 작은 소리의 차이가 약 6dB뿐이었다. 배경음악이 계속 깔려 있다는 뜻이라 효과음의 타이밍과 무게를 분리하지 못했다. 검은사막 사운드는 이 영상으로는 분석할 수 없다.

## 5. 아이온2 일반 스킬 (기본 스킬 참고용)

### 확인한 스킬
| 직업 | 스킬 | 눈에 띄는 형체 |
|---|---|---|
| 궁성 | 속사, 올가미 화살, 그리폰 화살 | 가는 화살 줄기 다발, 녹색 덩굴 올가미, 불꽃 날개 |
| 치유성 | 구원, 벽력, 쾌유의 광휘 | 위로 솟는 금빛 리본, 흰 번개 줄기, 녹금색 고리 |
| 마도성 | 겨울의 속박-겨울의 환영, 저주나무, 지옥의 화염 | 적 머리 위 흰 얼음 고리, 보라 연기 뒤 적이 나무로 변함, 화염 기둥 |
| 살성 | 암습, 맹수의 포효-문양 폭발, 나선베기 | 청록 직선 참격, 적마다 떠오르는 빛나는 문양, 흰 나선 궤적 |
| 검성 | 유린의 검-공중 결박, 칼날 날리기-칼날 화무, 분노의 파동 | 적을 묶는 청색 빛줄, 주황 초승달, 방사형 충격 |
| 수호성 | 나포, 비호의 일격, 방패막기-쇠약의 맹타 | 적을 끌어당기는 청색 사슬 빛줄, 번개 돌진, 흰 방패 섬광 |
| 정령성 | 협공: 파멸의 공세, 소환: 고대의 정령, 공포의 절규 | 금빛 마법진, 암석 정령, 보라 파편 폭발 |
| 호법성 | 타격쇄-암격쇄, 멸화, 쾌유의 주문 | 흰 봉 궤적, 방사형 흰 줄기, 금빛 원형 문양 |

### 기본 스킬에 맞는 특징
1. **크기가 작다.** 이펙트가 캐릭터 키의 1~3배 범위에 머물고 화면을 덮지 않는다.
2. **스킬마다 형체가 하나다.** 화살 줄기, 초승달, 고리, 문양, 사슬처럼 한눈에 구분되는 모양 하나가 중심이다.
3. **이펙트가 적에게 붙는다.** 바닥이 아니라 맞은 대상 위치에서 섬광과 파편이 터진다.
4. **상태 표시가 남는다.** 겨울의 속박은 적 머리 위 흰 고리, 문양 폭발은 적 몸의 빛나는 문양이 유지되다가 터진다. 무엇이 걸렸는지 읽힌다.
5. **길이가 짧다.** 한 번의 이펙트가 0.3~1초 안에 사라진다.
6. **밝은 낮 배경에서도 보인다.** 가는 선의 중심을 거의 흰색으로, 가장자리만 채도 높게 써서 밝은 풀밭 위에서도 읽힌다.
7. **화면 효과를 거의 쓰지 않는다.** 화이트아웃과 색 입히기는 드물고, 짧은 확대와 흔들림 정도만 있다.
8. **적의 반응이 타격감을 만든다.** 밀려나고, 뜨고, 묶이고, 변하는 모습이 이펙트보다 크게 읽힌다.

사운드는 영상에 배경음악이 있어 측정하지 않았다.

## 7. 참광 적용 기준

참광은 위에서 보는 자동 전투라서 스킬 등급에 따라 기준을 나눠 쓴다.

### 궁극기 → 로스트아크 문법
1. 스킬마다 위로 솟은 주인공 형체를 하나 정하고, 나머지는 공용 부품을 색만 바꿔 쓴다.
2. 밝은 빛 뒤에 어두운 불투명 덩어리를 먼저 깐다.
3. 빛은 흰 심·색·흐린 겉 3겹으로 그린다.
4. 절정은 0.1~0.3초, 바닥 잔해는 2~4초.
5. 절정 1~3프레임에 화면 효과를 몰아 쓴다.
6. 큰 타격 0.15~0.3초 전에 소리를 비우고, 저음 최대를 화면 섬광과 같은 순간에 맞춘다.

### 기본 스킬 → 아이온2 문법 (보조로 검은사막)
1. 스킬마다 구분되는 형체 하나만 쓴다 (줄기, 초승달, 고리, 문양, 사슬 중 하나).
2. 크기는 캐릭터 키의 1~3배, 길이는 0.3~1초.
3. 이펙트를 바닥이 아니라 맞은 적에게 붙인다.
4. 지속 효과는 적 위의 고리나 문양으로 표시해 유지한다.
5. 화면 전체 효과는 쓰지 않는다. 궁극기와의 격차가 여기서 생긴다.
6. 가는 선은 중심을 흰색으로 두어 어떤 배경에서도 읽히게 한다.
7. 평타와 연속기는 검은사막처럼 무기 궤적을 따라 띠를 남기고, 입자는 진행 방향으로 늘인다.
