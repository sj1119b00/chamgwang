# 참광 VFX 품질 기준

## 평가 항목 (각 100점, 목표 95)
애니메이션 작화 완성도 · 웅장함 · 규모감 · 화려함 · 타격감 · 공간감/입체감 · 역동성 · 이펙트 연결 · 색감/명암 · 캐릭터별 독창성 · 카메라 연출 · 타이밍 · 전장 환경 반응 · 상용 수준 완성도 · 다시 보고 싶은 매력

## 채점 규칙
- 반드시 실제 실행 화면(프레임 시트)으로 채점한다. 코드만 보고 점수를 주지 않는다.
- 구현자 점수는 참고용. 구현 내용을 모르는 별도 검증 에이전트가 시트만 보고 채점한다.
- 근거 없는 95점 금지. 어느 프레임이 왜 좋은지/부족한지 적는다.
- 반복 횟수·기능 구현 완료·구현자 만족은 완료 조건이 아니다.

## 시각 목표 (대표 궁극기에서 검증된 것)
- 전장이 계속 보인다: 주변광은 .4 아래로 오래 내리지 않는다. 암전 대신 색 조명과 대비.
- 주 이펙트는 **흰 핵 + 포화된 본색 + 어두운 테두리**가 분명한 단단한 모양. 분홍으로 뜨면 실패(가산 과다·블룸 과다).
- 높이가 있는 것은 바닥 그림자/바닥 선과 함께 그린다(벽, 낙하물, 파편).
- 정적과 폭발의 대비: 절정 직전에 반드시 멈춤이 있다.
- 한 프레임에 시각적 중심이 하나 있다.

## 금지
색만 바꾼 재사용 · 화면 전체 섬광으로 가리기 · 흔들림만 키우기 · 저해상도 GIF 확대 · 컷인/레터박스/암전 · 파티클 수만 늘리기 · 실행 없이 개선 주장

## 완료 조건
`VFX_MASTER_PLAN.md`의 목표 + 모바일 프레임 비용 측정 + 종료 후 상태 복구 확인 + 개선 전후 시트 존재 + 추가 개선 여지가 제한적이라는 근거.

## 대표 궁극기 기준 품질
`_gen/shots/z4.jpg` 이후 시트 (제로 슬래시). 다른 궁극기는 이 수준 이상이어야 한다.
