# 참광 궁극기 VFX 마스터 플랜

새 세션은 이 파일 → `VFX_NEXT_TASK.md` → `VFX_PROGRESS.json` 순으로 읽고 이어서 작업한다. 처음부터 다시 분석하지 않는다.

## 엔진 v3 (2026-11-24 오후, 목표 재설정: "로스트아크급")
17회 반복이 55~71점에서 정체한 원인은 부품이 아니라 **바탕**이었다: (a) 조명에 반응하지 않는 평평한 캔버스 바닥, (b) 모든 이펙트가 캐릭터 위에 스티커처럼 얹힘, (c) 가산 합성이 8비트에서 분홍·흰색으로 포화, (d) 얇은 선·절차적 도형 위주. 그래서 접근을 바꿨다.
1. **조명 받는 GL 지면** (`fx3.js`): 생성한 판석 그림(알베도)+파생 노멀맵을 매 프레임 광원 8개와 주변광으로 비춘다. 스킬이 터지면 실제로 그 색으로 바닥 요철이 드러난다. 캔버스 바닥은 폴백으로만 남음.
2. **두 레이어**: 지면 레이어('g': 마법진·균열·충격파)는 캐릭터 **발밑**에, 공중 레이어('o')는 위에.
3. **3D 메시 이펙트**: 회전체(고리·원통·원뿔·돔·기울어진 호), 리본, 벽, 기울인 판. 정점 셰이더가 월드(x, 바닥 y, 높이 z)를 투영.
4. **HDR**(half-float 타깃) + 색 램프: 본색은 포화된 채로, 흰색은 핵에만.
5. **그림 원화 × 램프 × 침식**: 회색 원화(검기·폭발·불꽃 장막·균열·번개…)를 3D로 배치하고 팔레트로 칠해 노이즈로 태운다. 이것이 품질의 핵심이었다(절차적 도형보다 압도적으로 좋음).
6. 키트는 `vfx3.js`(`K3`), 사용법은 **`VFX_KIT.md`**. 기준 궁극기는 `sk_sword.js`의 `ultZero`.
7. 헤드리스 캡처 `node _gen/cap/cap.js …`(7초/회, 병렬 가능) → 직업별 병렬 작업.

재개 순서: 이 파일 → `VFX_KIT.md` → `VFX_NEXT_TASK.md` → `VFX_PROGRESS.json`.

## 최종 목표
탑다운 전장을 그대로 둔 채, 궁극기를 쓰는 순간 그 전장이 액션 애니메이션의 명장면처럼 보이게 한다.
"이 궁극기를 보려고 게임을 한다"가 기준이다. 최종 미적 판단은 사용자가 한다.

## 절대 바꾸지 않는 것
- 탑다운 시점, 8방향 이동, 자동 전투 서바이벌, 현재 월드와 적의 공간 관계
- 궁극기 중에도 실제 전장이 보여야 한다 (암전으로 덮지 않는다)
- 금지: 횡스크롤 화면 전환, 컷신·영상, 캐릭터 클로즈업 컷인으로 화면 대체, 레터박스, 화면 전체 섬광으로 가리기
- 허용: 줌, 롤, 흔들림, 히트스톱, 감속, 조명·색보정, 후처리

## 개발 방향 (2026-11-24 결정)
1. 이펙트는 2D 캔버스 스프라이트가 아니라 **GPU 레이어(`gfx.js`)** 에서 월드 좌표(x, 바닥 y, 높이 z) 도형으로 그린다.
   바닥에 눕는 쿼드(FSY .58 압축), 세운 빌보드, 바닥 선에서 위로 뽑아 올린 벽, 두 점 사이 리본.
2. 모양은 **셀 셰이딩 필드**(어두운 테두리 / 본색 / 흰 핵 3톤)를 노이즈로 깎고, 12fps 계단 시간으로 움직여 "그린 프레임"처럼 보이게 한다.
   빛(벽·광원)만 부드러운 가산 그라데이션을 쓴다.
3. 전장 조명: 암전 사각형 대신 최종 셰이더에서 장면에 주변광(ambient)과 색 조명 4개를 곱한다. 굴절 버퍼로 공간 왜곡.
4. 임팩트 프레임은 장면만 2색 잉크로 바꾸고 GPU 이펙트는 제 색을 유지한다.
5. 컷인 이미지(`*_cut1/2.webp`)와 레터박스는 새 궁극기에서 쓰지 않는다.
6. 각 궁극기는 4단계(전조 → 해방 → 절정 → 여운)를 갖되, **구조 자체가 직업마다 달라야** 한다(색만 바꾸기 금지).

## 파일 구조
- `fx3.js` 조명 지면 + 메시 이펙트 렌더러(HDR), `vfx3.js` 이펙트 키트(K3) — **신규, 주력**
- `gfx.js` GPU 이펙트 레이어 (`window.GFX`): 셰이더 모드 0~14, 쿼드 제출(floor/bill/line/wall/screen/pose), 파티클, 조명, 굴절
- `cine.js` 연출 감독 (`RPG.sv.cine`): 카메라·임팩트 프레임·사운드 + **GPU 키트**(gSlash, gRing, gStar, gPuff, gDebris, gLevitate, gSparks, gMotes, gWall, gSlip, gSpeed)
- `sk_<cls>.js` 직업별 궁극기 본문 (`// ---- ultimates` 아래)
- `index.html` 최종 합성 셰이더(FINFS)에 vfx/굴절/조명 연결, `glFrame`에서 `GFX.render`
- 검증: `_gen/devsrv.py`(포트 8779, 캐시 없음, `/__shot/<이름>` 저장) + `_gen/go.js`의 `__go(cls, ult, [초...], 파일, {cols,tw})` → `_gen/shots/`
- 배포 사본·Git: `_gen/build_deploy.py` → `_gen/deploy`(github sj1119b00/chamgwang). push는 사용자 확인 후.
