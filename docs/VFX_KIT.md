# 참광 VFX 키트 사용법 (엔진 v3, 2026-11-24)

스킬·궁극기 연출은 전부 이 키트로 만든다. 새 세션·서브에이전트는 이 문서와 `sk_sword.js`의 `ultZero`(기준 궁극기)를 읽고 시작한다.

## 구조
| 파일 | 역할 | 수정 권한 |
|---|---|---|
| `fx3.js` (`window.FX3`) | 조명 받는 GL 지면(알베도+노멀맵, 광원 8개), 3D 메시 이펙트 렌더러(HDR), 재질 셰이더 | 엔진 담당만 |
| `gfx.js` (`window.GFX`) | 파티클, 광원(`GFX.light`), 주변광(`GFX.ambient`), 굴절(`GFX.ripple`), 타이머(`GFX.add`) | 엔진 담당만 |
| `vfx3.js` (`window.K3`) | **이펙트 키트** — 아래 조각들 | 엔진 담당만(추가 요청은 기록) |
| `cine.js` (`RPG.sv.cine`) | 카메라(zoom/roll/cam/shake), 사운드(SND), 피해 스윕(sweep) | 엔진 담당만 |
| `sk_<cls>.js` | 직업별 스킬·궁극기 본문 | 그 직업 담당 |

화면 합성 순서: **지면(조명) → 지면 레이어 이펙트('g': 마법진·균열·충격파 — 캐릭터 발밑) → 캐릭터 스프라이트 → 공중 레이어 이펙트('o') → 블룸·후처리**.

## 좌표
- 월드 `(x, y, z)`: `y`는 바닥 좌표(화면 세로 방향, 이미 .58로 눌린 단위), `z`는 높이(화면 위로 1:1).
- 영웅 바닥 위치는 `pl.x, pl.gy`. 몸 높이 상수 `BODY`. 화면 반폭/반높이는 `view()` → `{hw,hh}`.
- 바닥에 눕는 도형의 반지름 `r`은 가로 기준(세로는 자동으로 .58).

## 핵심 원칙 (품질 기준)
1. **그림 원화 × 색 램프 × 침식 × 3D 배치.** 회색 원화(검정 배경)를 팔레트(어두운 테두리 d / 포화된 본색 b / 흰 핵 h)로 칠하고, 노이즈로 타 들어가며 사라지게 한다. 단색 도형·얇은 선·흰 덩어리는 실패.
2. **흰색은 핵에만.** 화면이 분홍·흰색으로 뜨면 gain을 낮추고 본색이 보이게 한다.
3. **지면이 반응한다.** 모든 타격에 `GFX.light`(바닥이 그 색으로 물듦) + 바닥 흔적(crack/gash/shock) + 파편·먼지.
4. **단계가 있다.** 전조(응축·마법진·주변광 하강) → 시전 → 전개 → 절정(히트스톱·흔들림) → 여운(잔불·흉터·주변광 복귀).
5. **암전·컷인·레터박스·화면 전체 섬광 금지.** 어둡게 할 때는 `GFX.ambient(.3~.5, …)`만 쓴다(전장은 계속 보인다). `Cn.setDark`, `Cn.cutin`, `ov.lbT`, `Cn.impact`의 2색 프레임, `Cn.wash`는 쓰지 않는다.
6. 궁극기 > 일반 스킬. 일반 스킬은 조각 1~3개 + 광원 1개로 짧고 선명하게(0.3~0.8초), 궁극기는 전장 전체.
7. 직업마다 구조가 달라야 한다(색만 바꾼 재사용 금지).

## 팔레트
`K3.PAL`: `crimson`(검사), `gold`, `violet`(마법사 번개), `azure`(권사 기공), `jade`(도사), `flame`(화염술사). 직접 만들 때 `{d:'#어두운', b:'#본색', h:'#핵', l:'#바닥광', s:'#불티'}`.

### 키트 갱신 (2026-11-24 12:30, 하위 호환)
- **색 램프 4단계**: 팔레트에 `m`(본색과 핵 사이의 중간 고온색)을 넣으면 "어두운 테두리 → 본색 → m → 흰 핵"으로 칠해진다(예: 진홍 `m:'#ffb66a'` 금빛). 직접 만든 팔레트에도 `m`을 넣을 것 — 한 가지 색·한 가지 밝기로 보이는 문제를 없앤다. `K3.PAL.silver`(차가운 은색) 추가: 마법진은 은색, 타격은 직업색처럼 **두 색 대비**를 쓰면 좋다.
- **최종 합성이 색상을 보존**한다(밝아져도 흰색으로 날아가지 않음). 그래도 gain을 과하게 올리지 말 것.
- `sigil` 핸들: `h.pal`(살아 있는 동안 색 변경), `h.kick()`(맥동), 쓰이는 동안 선두 불티.
- `seam`: 그림 원화 기반의 찢어진 틈 + 바닥에 비친 빛 + 달리는 불티, `h.kick()`.
- `wall`: 뒤에 어두운 연기 띠, 들쭉날쭉한 높이, 떨어져 나가는 불꽃 조각. 옵션 `rise`(솟는 시간) `ord`(깊이 순서: 보통 벽의 y) `licks:0` `smoke`.
  **화면에서 세로에 가까운 선(약 55° 초과) 위의 벽은 납작한 선으로 보인다** — 벽·장막은 가로~대각 방향으로 세우고, 뒤쪽(화면 위)은 높게 앞쪽은 낮게.
- `debris`: `size0`~`size`(큰 판석 조각), `petals`: 크고 회전.
- 스프라이트(적·영웅)는 가장 센 광원 쪽 가장자리에 **테두리광**을 받고, 그림자가 광원 반대쪽으로 길어진다 → 큰 타격에는 반드시 `GFX.light`를 넣을 것(반경 넓게, z 150~300).
- 궁극기 구도 교훈(대표 궁극기 검증에서): ①절정에 **하나의 초점**(중앙 빛기둥·폭발 등, 색도 다르게)을 두고 그 직전에 0.1초 숨죽임 ②주인공이 이펙트에 가려지지 않게 ③여운에 스킬의 모양이 바닥 흉터로 남게.

### 키트 갱신 2 (2026-11-24 13:30, 하위 호환)
- **카메라 기울임 `Cn.tilt(t, k)`**: t 0 = 평소 탑다운, 0.2~0.3 = 카메라가 바닥 쪽으로 내려앉아 전장이 원근으로 물러남(먼 줄은 좁게, 가까운 줄은 크게). k는 도달 속도. 화면 중앙이 1/(1-t)배 확대되므로 `Cn.zoom`을 그만큼 낮춘다(예: tilt .28이면 zoom .66 ≈ 실제 .92). 궁극기 끝에 `Cn.tilt(0, 2.5)`(ultStop이 자동으로 0으로 되돌리지만 여운에서 천천히 올리는 편이 좋다). **정지 화면에서도 카메라 연출이 보이게 하는 유일한 수단** — 전조에서 조금(.1), 절정 직전에 깊게(.24~.3), 여운에서 복귀.
- `K3.cres(..., {keep:true, idlePal, idle, max})` → 핸들 반환: 그려진 뒤 공중에 멈춰 서서(idlePal 색, idle 밝기) `h.kick()`으로 맥동, `h.end()`로 타 사라짐. "공중에 남는 참격"은 **곧은 선(seam) 대신 이것**을 쓴다 — 검증자 다섯 명이 곧은 선을 싸구려 레이저로 읽었다.
- `K3.crack(..., {ry})`: 세로(깊이) 방향으로 늘려 세로 화면 끝까지 닿게.
- 교훈: 화면에 곧은 선·곧은 가장자리·균일한 폭이 보이면 감점된다. 그림 원화의 실루엣(초승달·불꽃·번개)으로 대체하고, 한 궁극기 안에서 색을 세 번 바꾼다(예: 강철빛 → 진홍 → 금).

### 키트 갱신 3 (2026-11-24 14:20, 하위 호환)
교차 검증(10개 궁극기 평균 68)에서 "모든 궁극기가 같은 별 모양 폭발·얇은 타원 충격파·검은 거미줄 균열로 끝난다"는 지적에 대한 공용 조치.
- 새 원화(회색, `K3.art`의 `tex`로 사용): `v3_burst_sword`(X자 참격+칼날 파편), `v3_burst_arcane`(룬 고리+다각 별), `v3_burst_ki`(겹겹의 두꺼운 압력 고리+암석), `v3_burst_lotus`(빛의 연꽃), `v3_burst_fire`(덩어리진 비대칭 폭염+연기), `v3_shock_thick`(두꺼운 충격파 전면, 가운데 빔), `v3_fissure_b`(세 갈래 비대칭 균열+들린 암반).
- `K3.burst`의 섬광이 **직업별 원화로 자동 교체**된다(`K3.btex()` = 현재 직업의 폭발 원화). 예전 별 모양은 `ftex:'v3_xburst'`, 다른 원화는 `ftex:'…'`.
- `K3.shock`은 `r>=400`이면 두꺼운 그림 전면(`v3_shock_thick`)을 쓰고 얇은 선 고리를 뺀다. 예전 모양은 `thick:0`.

- 정점 광원 상한: 반경 `hw*1.6` 이하, 세기 1.2 이하(화면 전체 섬광으로 읽히지 않게).

#### 1. 적 피격 반응
엔진이 자동으로 해 주는 것(직업 파일에서 할 일 없음): `dmg()`를 맞은 적은 **흰 실루엣으로 번쩍**이고 **크기가 1.3배로 튀며 맞은 방향으로 젖혀진다**(0.16초). `hitFx`/`K3.hit`의 섬광은 2배로 커졌고 가운데 흰 점이 생겼다.

| 함수 | 설명 |
|---|---|
| `K3.knock(e,{from:[x,y] \| dir, dist, up, stun, fx:0})` | 밀려남·띄우기. `dist` 월드 단위로 실제 그만큼 미끄러진다(120 밀침 / 300 강타 / 500+ 날아감, 기본 220). `up` 띄우는 속도(900 살짝 / 1500 몸 1.5배 높이 / 2200 높이). 날아가는 동안 기절, 발밑 먼지와 속도선. 무거운 적은 1/3, 보스는 안 밀림. |
| `dmg(e,d,{push:300,up:1500,...})` | `dmg` 옵션으로도 같은 넉백을 건다(`push`=dist, 기준점은 `sx,sy`). 기존 `kb`/`launch`도 그대로 동작(기존 `kb:1`은 40밖에 안 밀려 화면에서 안 읽힌다 → `push`를 쓸 것). |
| `K3.ehit(e,{pal \| c:'#rrggbb', pw, dir, ring:0, light})` | 스킬의 **주 타격 한 방** 표시: 몸 위 백열 별 + 타격 방향 줄기 + 발밑에서 튕겨 나가는 고리 + 방향 불티. `pw` 1 보통 / 1.6 강타. 틱 피해에는 기존 `hitFx`를 쓰고, 한 프레임에 `ehit` 6개 이하. |
| `K3.mark(e,kind,{dur,pal,s,tex,max,onEnd})` → h | **적에게 붙어 유지되는 상태 표시**. kind: `burn`(몸을 타고 오르는 불꽃+불씨) `shock`(몸을 감는 아크) `frost`(발밑 얼음 고리+옅은 껍질) `seal`(머리 위에서 도는 문양) `brand`(가슴의 문양+발밑 고리). 몸에 상태 색이 입혀진다. 다시 걸면 시간 갱신 + 중첩(`max`까지, 중첩마다 커짐). 기본 색: burn flame / shock violet / frost azure / seal jade / brand crimson(`pal`로 변경, seal·brand는 `tex`로 문양 교체: `v3_circ_<cls>` 등). |
| `h.pop({pw,quiet})` | 표식을 **터뜨린다**(몸 위 폭발 섬광+고리+불티, 중첩 수만큼 커짐). 피해는 호출 쪽에서 준다. `h.end()` 조용히 제거, `h.live()`, `h.n`(중첩). |
| `K3.marked(e,kind)` | 살아 있는 표식 핸들 또는 null. |
| `K3.popAll(kind,(e,{n})=>{ dmg(...) },{full:10,pw})` | 그 종류의 표식을 전부 터뜨린다(영웅에 가까운 순, 앞의 `full`개만 전체 연출). 반환 = 터진 수. |

```js
// 아이온2 문법: 걸어 두고 → 터뜨린다
inCircle(x,y,300,e=>{ dmg(e,D*.3,{push:160}); K3.mark(e,'burn',{dur:4,max:3}); });
after(1.2,()=>K3.popAll('burn',(e,{n})=>{ dmg(e,D*n,{push:320,up:1400,crit:true}); }));
```
함정: 표식 그림은 동시에 64개까지만 그린다(그 이상은 상태만 걸리고 그림 없음). `ultStart`는 무대를 비우므로 궁극기 시작 전에 걸린 표식의 그림은 사라진다(핸들은 살아 있어 `pop`은 된다) — 궁극기 안에서 다시 걸 것. 적이 죽으면 표식도 끝난다(`pop`하려면 죽이는 피해보다 먼저).

#### 4. 안정 빔
`K3.ray(x,y,z,dir,{len,w,dur,grow,out,pal,gain,scar:0,scarLife,tip:0,light:0,delay})` → h
- (x,y) 높이 z에서 바닥 방향 `dir`(라디안)으로 나가는 광선. **흰 심 + 흐르는 본색 + 흐린 겉 3겹**, 뒤에 어두운 몸통, 바닥에 비친 빛, 시작점 섬광, 끝점 불덩이+별+불티, 지나간 자리의 식는 자국. 탑다운 원근이 맞는다(화면 위아래 방향은 .58로 짧아짐).
- **길이는 `grow`초(기본 .2)에 한 번 자라 `len`으로 고정**된다. 프레임별 난수 없음(움직임은 빔을 따라 흐르는 노이즈와 3% 이하의 느린 호흡뿐). `dur`초 유지(기본 1.6) 후 `out`초(.3) 동안 **시작점에서 끊겨 남은 줄기가 끝점으로 빨려 나가며** 끝난다.
- 핸들: `h.x,h.y,h.z,h.dir,h.w,h.a`를 매 프레임 바꿔도 된다(회전 빔: `GFX.add(dur,(k,t)=>{ h.dir=a0+k*1.2; })`). `h.x2,h.y2`/`h.tip()` = 끝점(피해 판정용: `inLine(h.x,h.y,h.x2,h.y2,h.w*1.4,e=>…)`), `h.cur` 현재 길이, `h.end()` 조기 종료, `h.dead`.
- 크기: `w`는 본색 반폭. 일반 스킬 45~70, 궁극기 110~200. `len`은 화면 밖까지(`Math.hypot(hw,hh)*1.2`). 시작점은 영웅에서 `w*1.2`쯤 앞에 둘 것(섬광이 영웅을 가린다).
- 함정: `h.len`을 유지 중에 바꾸지 말 것(그게 "길어졌다 짧아졌다"). 빔이 도는 동안 끝점이 지나간 자리에 그을음이 찍힌다(최대 26개). 궁극기 굵은 빔은 한 번에 1~2개(드로우 약 12개 + 볼륨 1개씩). 빔 굵기를 키우는 연출은 `h.w`를 **단조 증가**로만.

```js
const r=K3.ray(x0+Math.cos(a)*140,y0+Math.sin(a)*140*.58,BODY*.62,a,{len:Lb,w:150,dur:2.2,pal:'azure'});
```

#### 5. 카메라 (`Cn`)
확인 결과: `Cn.cam/zoom/roll/tilt`는 원래도 현재 값에서 지수적으로 따라가서 순간이동은 없었다. 다만 줌은 0.1초 만에 붙어 "툭 끊기는" 느낌이었고, 시간·이징을 지정할 방법이 없었다. **`Cn.sweep`은 카메라가 아니라 피해 파동, `Cn.drone`은 저음 사운드다(착각 주의).**

| 함수 | 설명 |
|---|---|
| `Cn.move({x,y,zoom,tilt,roll,home:1},dur,ease)` | **지금 카메라 값에서 목표까지 `dur`초 동안** 이징(`'io'` 기본·느림-빠름-느림 / `'out'` 급히 가서 안착 / `'in'` 점점 빨라짐 / `'lin'`). 적은 속성만 움직인다. x,y는 `Cn.cam`과 같은 카메라 중심(영웅을 보려면 `y0-BODY*.6`). 끝나면 그 자리에 머문다. 도중에 다른 `Cn.move`를 부르면 그 순간 값에서 이어진다. |
| `Cn.back(dur=.8,ease)` | 게임 카메라(영웅 추적·줌 1·기울임 0·롤 0)로 부드럽게 복귀. 잔해 단계에서 `ultStop()` 0.8초 전에. |
| `Cn.zoom(z,k)` | `k`를 주면(2 느림 ~ 12 빠름) 그 속도로 미끄러져 간다. `k` 없으면 예전과 같음. |

- 위치 이동(`x,y`,`Cn.cam`)은 **궁극기 중(lock)에만** 먹는다. 줌·기울임·롤은 언제나.
- 복귀 보장: `ultStop()`이 진행 중인 move를 끊고 줌 1·롤 0·기울임 0·영웅 추적으로 **부드럽게**(0.3~0.5초) 되돌린다. `__smoke`/`__perf`의 `restored.zk`는 1로 나온다.
- 단계별 권장: 준비 `Cn.move({x:x0,y:y0-BODY*.6,zoom:1.3,tilt:.08},.5)` → 축적 `Cn.move({zoom:1.5,roll:.04},1.2,'lin')`(느린 밀기) → 절정 `Cn.move({zoom:.78,tilt:.22,roll:0},.22,'out')`+`Cn.shake(1)` → 잔해 `Cn.back(1)`.
- 함정: tilt t는 화면 중앙을 1/(1-t)배 키운다(줌을 그만큼 낮출 것). `after()`는 실제 시간이라 히트스톱 중에도 흐른다 — 카메라도 실제 시간으로 움직인다.

#### 6. 캡처 도구
- `__piece`(= `cap.js --piece`)가 이제 **영웅의 모든 자동 시전을 묶는다**(쿨타임 항목이 아직 없던 스킬, 공용 쿨 `V.gcd`, 평타, 남아 있던 장판·투사체·타이머 포함). 스킬 단독 캡처에 다른 스킬이 섞이지 않는다. 자동 시전을 보고 싶으면 `--o "{quiet:false}"`.
- `--o "{dummies:[[dx,dy],[dx,dy,'brute'],…]}"`: 전장을 비우고 영웅 기준 위치에 **제자리에 서 있는 적**을 세운다(반응·표식·넉백 확인용; `still:false`면 걸어온다, `dummies:[]`면 적 없음). `keep:true`는 앞 조각의 잔여를 지우지 않음.
- 캔버스는 약 1012×468(dpr 2)이다. `cw`는 1012 이하로(그보다 크면 검은 여백).
- `GFX.add` 콜백은 **렌더된 프레임에만** 돈다. 캡처 시각 사이가 길면 그 사이의 콜백 내부 사건(예: 빔 종료 시 자국 남기기)이 건너뛰어진다 → 끝나는 순간 전후로 시각을 촘촘히.
- 헤드리스 캡처에서는 게이지가 차면 저장된 궁극기가 자동 발동한다(`surv.js`의 dev 훅, `navigator.webdriver`). 실제 게임은 버튼으로만.


**크기 감각(다시)**: 카메라 배율 0.24 → 월드 100 = 화면 24px, 화면 세로 전체 ≈ 월드 950(줌 1). **높이 z도 화면 위쪽으로 1:1로 올라가므로** 키가 큰 것(신 형체·빛기둥·구름)은 영웅보다 화면 위에 그려진다. 줌 .7이면 세로 ≈ 1350. 신 형체 `h` 700~900이 "화면 높이 절반"이다(1500 넘기면 머리가 화면 밖).

#### 1. 디테일 암석
| 함수 | 설명 |

#### 2. 모아지는 기 (축적)
`K3.gather(x,y,z,o)` → `H{x,y,z,u,dead,release(q),end()}`
- `dur`초 동안 **속도·밝기·밀도가 단조 증가**: 화면 밖(`R`)에서 나선으로 빨려 드는 가늘고 긴 줄기(흰 심 + 팔레트 불티색, 진행 방향으로 늘어남, 도착하면 소멸), 수렴점을 겹겹이 조여 드는 껍질 `shells`개(넓고 흐리게 시작 → 안쪽으로 수축하며 밝아짐, 내부 결이 흐름, 주기가 점점 빨라짐), 커지는 핵(그림 핵 + 볼륨 `orb` 1개), 주위를 도는 짧은 전류 호·불티와 느린 빛 알갱이, 바닥에서 떠올라 빨려 드는 돌 부스러기·먼지, 수렴점 아지랑이(굴절 왜곡), 바닥 빛 웅덩이와 `GFX.light`가 점점 강해짐.

#### 0. 새 메시 종류 (`FX3.solid` / `K3.rocks` / `K3.chunks`의 kind)
| kind | 모양 |
|---|---|
| `stone` | 깨진 바위: 다옥타브 노이즈로 밀린 구 + 평면 쪼개짐 5~6개(평평한 단면과 진짜 모서리) + 오목부 |

| `flag` | 층리 판석: 층마다 폭이 달라 계단 턱이 형태에 드러남(셰이더 층리 띠 기본 4) |

#### 1. 빙하·얼음 결정 군집
`K3.ice(x,y,o)` → `{L,dead,shatter(),end()}`: 서리 내린 바닥(맥상 서리 + 눈 테두리 데칼)을 뚫고 결정 군집이 솟는다(살짝 오버슛). 큰 결정 하나 + 바깥으로 기운 작은 결정들, 얼음 칩·냉기 안개·반짝임. `dur` 뒤 **날카로운 파편 + 흰 가루로 부서짐**(`end:'melt'`이면 가라앉으며 녹음, `'none'`이면 `h.shatter()`를 직접).

#### 2. 운석

#### 4. 신 움직임 (`K3.deity(x,y,{rig:1,…})`)
`rig:1`이면 관절 있는 새 신(키트 9의 기존 신은 `rig` 없이 그대로).
- **아래에서 위로 응결**(`in` .9초: 옷자락 → 가슴 → 팔 → 머리 순, 형성 높이에서 안개 입자가 나선으로 빨려 듦), **숨쉬기**(가슴·어깨 부피), 처음엔 고개를 숙였다가(`bow`) **고개를 들어 내려다봄**(`look`; 고개가 들리면 눈이 켜짐), **어깨-팔꿈치-손 2마디 팔**(위팔·아래팔 볼륨 따로), 자세 보간은 무게감 있는 이징(`heavy` = 오버슛 후 안착), **늦게 따라오는 소매 안개**(손이 지나간 자리의 기록으로 그린 리본 — 2차 움직임) + 몸의 기울기를 늦게 따라가는 옷자락, **흩어지는 퇴장**(위로 떠오르며 풀리고 안개 입자가 흩날림). 몸통 두께·자기 그림자는 `solid`(0~1, .55)로.
- 핸들: `pose(name|{A,e,b,L,hp},dur=.6,ease='io'|'out'|'in'|'heavy',arm=-1|0|1,fn)` (차례로 줄 섬), `look(hp,dur)`, `act('smite',{arm,up,hold,down,hit(H)})` = 팔을 머리 위로 들었다가(.5) 멈춤(.1) 내리침(.13, 그 순간 손에 섬광·불티 + `hit`) 후 무게감 있게 복귀, `act('point',{arm,to:[x,y],hit})` = 손끝으로 그 지점을 가리킴, `hand(i)`/`head()` 월드 좌표(빛줄기 시작점), `busy()`, `end()`.
- 자세 이름 `K3.POSE`: `rest open raise down press up smite point bow`. A=방위(0 옆, π/2 카메라 쪽), e=높이, b=팔꿈치, L=앞으로 숙임, hp=고개.
```js
const G=K3.deity(pl.x,pl.gy-120,{rig:1,h:850,pal:'jade',dur:4});
after(1.6,()=>G.act('smite',{hit:H=>{ const p=H.hand(1); /* 피해 + K3.impact(...) */ }}));
```
비용: 드로우 9 + 볼륨 7(옷자락·가슴·머리·위팔2·아래팔2). 기존 신(드로우 9 + 볼륨 4)보다 볼륨 3개 많다 — 같은 순간 다른 큰 볼륨은 2개 이하로.

#### 5. 검증 도구 (`_gen/v3/h.js`, `_gen/v3/k10t.js`, 개발 전용)
- `__seed(n)`: Math.random 고정. `__cmp(cls,ult,ts,name,{seed,px})`: 워밍업 뒤 시드·RT 고정으로 궁극기 시트를 찍는다. 같은 코드·같은 시작 상태면 바이트까지 같은 이미지. **주의**: 페이지 로드 직후의 실시간 루프(영웅 x 1206.33/1207.57, 카메라, 텍스처 로드 시점)가 시작 상태를 두 가지 정도로 갈라 놓아 같은 코드도 다른 이미지가 나올 수 있다(값이 몇 가지로만 반복됨). 병렬로 찍지 말고 순차로 2~3회 찍어 기준과 **차 0이 한 번이라도 나오면 동일**로 판정한다(이번 작업: 네 개 모두 차 0 확인).
- `__cost(cls,[[이름,fn,초],…])`: 빈 전장에서 부품 하나의 최대 드로우·볼륨·입자. `__k10row(kinds,o)`: 새 메시를 크게 나란히. `__cpiece`: 시드 고정 조각 캡처.

함정: 새 종류는 `ero`(침식)로 사라질 때 깊이 버퍼가 남지 않으니 걱정 없다. 그러나 **반투명 얼음 뒤의 같은 얼음**은 깊이 때문에 비치지 않는다(앞의 결정만 보임). 큰 돌·결정(`s` 400 이상)은 화면을 크게 가리니 영웅 뒤에 둘 것(`ice`·`rocks`는 영웅 앞의 것을 자동으로 비킨다).
