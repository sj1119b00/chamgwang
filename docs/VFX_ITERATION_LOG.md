### 7회 — 나머지 9개 궁극기 개별 재설계 (`r1`, `m1`,`m2`, `f1`,`f2`, `s1`,`s2`, `p1`~`p3`)
구조를 직업별로 다르게 잡았다(색만 교체 금지).
- 소드 레인: 바닥 마법진 + **머리 위(높이 2500) 하늘 마법진** → 검이 높이에서 떨어지며 그림자가 조여듦 → 꽂힌 채 남음 → 탑 크기 대검 → 꽂힌 검이 가까운 순서로 빛기둥이 되어 응답.
- 헤븐 썬더: 구름 천장이 카메라 위로 밀려옴 → 지팡이에서 각 적에게 표식 실 → 천장에서 표식마다 낙뢰 → 한 점에 수렴하는 기둥 → 몸에서 몸으로 연쇄.
- 메테오 폴: 바닥에 커지는 그림자 → 같은 사선으로 작은 운석들 → **카메라 높이에서 화면만 한 크기로 보이다 그림자 위로 줄어드는** 본체 → 화염·연기 기둥.
- 하이퍼 빔: 공기 압축 3단(링이 조여들 때마다 바닥 균열) → 한 바퀴 휘두르는 빔(바닥 반사광, 끝에서 파편) → 전방위 방출.
- 솔라 크래시: 머리 위 태양(코로나 셰이더) + **모든 적이 태양 반대쪽으로 긴 그림자** → 뛰어올라 주먹으로 내리꽂음.
- 스톤 레인: 봉인진 → 빛의 사슬로 속박 → 가속하는 북소리에 맞춘 낙석 → 빛을 가리는 거석 → 땅에서 솟는 바위 3겹.
- 스피릿 킹: 노이즈에서 타 들어오듯 형성되는 반투명 신령 → 눈 뜸 → 손바닥 4회 → 하늘을 덮는 손.
- 파이어 스톰: 셰이더 불기둥 깔때기 6개가 전장을 훑음 → 귀환·합체 → 화면을 채우는 하나.
- 드래곤 블레이즈: 머리 경로를 시간 함수로 샘플해 몸통을 그림(프레임률 무관) → 저공 한 바퀴 → 카메라 위로 상승 → 급강하.
- 수정한 결함: 파티클 핵 색이 흰색 고정(연기·구름이 흰 덩어리) / 화룡·회오리가 그린 프레임 수에 의존 / 태양 과노출 / 신령이 불투명해 전장을 가림 → 반투명 / 번개가 굵은 지그재그 → 사인 흔들림+작은 잡음.
